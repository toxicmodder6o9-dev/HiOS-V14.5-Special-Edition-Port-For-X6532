## 🚀 Features & Changes

- 🗑️ **Debloated & Cleaned:** Removed all unnecessary Transsion services (AI, Smart Panel/Hub) for a leaner, faster system.
- 🔒 **Security & Privacy:** Fixed Transsion App Lock and patched core security vulnerabilities *(My Own Implementation)*.
- 🛠️ **Hardware Fixes:** Fully resolved bugs with the Gyroscope, In-Call UI Volume, and Offline Charging.
- 🎨 **UI Aesthetics:** Added rounded corners for a modernized, polished interface experience.
- 🎛️ **Control Center Alignment:** Fixed control center paddings for a more uniform and visually balanced layout.
- 🔓 **Tile Limits Removed:** Completely eliminated the control center's maximum 24 tiles limit for unrestricted customization.
- 🔄 **System Apps:** Added and updated all Transsion system applications, including the latest Dynamic Bar.
- 🔍 **Smart Navigation:** Added Circle to Search paired with a clean gesture navbar **(Note: Requires updated Google Play Services for CTS)** *(My Own Implementation)*.
- 🧩 **Widget Control:** Introduced a custom edit button for supported widgets *(My Own Implementation)*.
- ⚡ **Performance Optimized:** Tuned refresh rate, overall performance, and RAM management specifically tailored for low-end hardware.
- ✨ **Under the Hood:** Various other major system improvements and stability enhancements.

## 📌 Important Notes

1. **Let it Settle:** After the first boot, please allow the ROM **5 to 10 minutes** to fully optimize before heavy use.
2. **RAM Expectations:** Minor lags during high-intensity usage are normal, particularly on the 3GB RAM variant.
3. **Device Properties:** Props have been intentionally kept to KL5 to maintain DTS audio functionality.
4. **Play Integrity:** Use **[THIS](https://github.com/evoker0/AlwaysStrong)** for strong Integrity.
5. **Custom Kernels:** Please **do not** report bugs if you decide to flash a different custom kernel over this setup.
